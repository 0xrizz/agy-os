# Spec-Driven Development (SDD) Experiment

Area eksperimen untuk pengembangan metodologi **Spec-Driven Development (SDD)**.

---

## 📌 Konsep Utama

Spec-Driven Development menempatkan spesifikasi formal (kontrak API, skema data, kriteria penerimaan) sebagai *single source of truth* sebelum penulisan kode implementasi.

## 📂 Struktur Eksperimen

- Masukkan dokumen spesifikasi, validator skema, atau runner pengujian SDD di folder ini.
