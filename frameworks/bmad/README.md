# Behavior-Driven / Multi-Agent Development (BMAD) Experiment

Area eksperimen untuk pengembangan metodologi **BMAD (Behavior-Driven / Multi-Agent Development)**.

---

## 📌 Konsep Utama

BMAD berfokus pada pembagian peran spesifik antar agen (Architect, Builder, Reviewer, Tester) dan koordinasi alur kerja agen berbasis perilaku (behavior-driven) untuk menyelesaikan tugas-tugas kompleks secara otonom.

## 📂 Struktur Eksperimen

- Masukkan spesifikasi perilaku agen, skenario pengujian agen, atau protokol komunikasi agen di folder ini.
