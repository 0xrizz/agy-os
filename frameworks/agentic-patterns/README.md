# Agentic Design Patterns Experiment

Area eksperimen untuk pengujian dan katalogisasi **Agentic Design Patterns**.

---

## 📌 Konsep Utama

Mengeksplorasi dan mengimplementasikan pola-pola desain sistem agen AI, seperti:
- **Reflection / Self-Correction**
- **Tool Use & Orchestration**
- **Planning & Task Decomposition**
- **Multi-Agent Collaboration Protocols**

## 📂 Struktur Eksperimen

- Simpan pola arsitektur, template petunjuk (prompts), atau modul utilitas agen di folder ini.
