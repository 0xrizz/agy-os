## 1. Overview & Architecture Goals

### Context
Objective 07 extends the Antigravity custom installer suite ([harness/agy-script/](file:///d:/dev/agy-os/harness/agy-script/)) with a `--target-dir <path>` CLI parameter, enabling isolated installation of the full ECC component surface into any external repository without modifying the master harness at [agy-os](file:///d:/dev/agy-os). Prior to OBJ-07, all five installer scripts derived their installation root by resolving `__dirname` or `SCRIPT_DIR` upward — hardcoding `d:/dev/agy-os` as the only possible destination. OBJ-07 decouples path resolution from script location, making the installer a portable, reusable tool.

### Goals
- Refactor all 5 scripts to parse `--target-dir <path>` with a CWD fallback maintaining 100% backward compatibility when the flag is omitted.
- Scaffold the full `.agents/` directory tree (`agents/`, `rules/`, `skills/`, `workflows/`, `scripts/`, `scripts/lib/`) inside any given `--target-dir`.
- Copy [docs/OBJ-07/artifacts/ecc-items.json](file:///d:/dev/agy-os/docs/OBJ-07/artifacts/ecc-items.json) into `<targetDir>/.agents/ecc-items.json` so that verification is 100% self-contained within the target directory.
- Mirror runtime scripts from [.agents/scripts/](file:///d:/dev/agy-os/.agents/scripts/) and [.agents/scripts/lib/](file:///d:/dev/agy-os/.agents/scripts/lib/) into `<targetDir>/.agents/scripts/` with zero hardcoded master harness paths inside deployed files.
- Establish a committed minimal test sandbox at [test/repo-experiment-01](file:///d:/dev/agy-os/test/repo-experiment-01) and prove 1:1 parity via `verify-installation-agy.js --target-dir`.
- Extend `uninstall-agy.sh --target-dir <path>` to clean up exclusively `.agents/` inside the target directory, leaving all project source files untouched.

### Non-Goals
- Modifying upstream [ECC/](file:///d:/dev/agy-os/ECC) source files.
- Modifying target repository [website](file:///d:/CLAUDE-PROJECT/website) directly.
- Changing the ECC manifest schema or component selection logic.
- Installing different component sets per target repository (OBJ-07 targets identical 1:1 parity).

## 3. Technical Design

### 3.1 `--target-dir` CLI Parsing Pattern

All 5 scripts use an identical argument-parsing strategy to derive `targetDir`:

**Node.js scripts** (`install-apply-agy.js`, `post-install-agy.js`, `verify-installation-agy.js`):
```javascript
// Parse --target-dir from CLI args
const args = process.argv.slice(2);
let targetDirArg = null;
for (let i = 0; i < args.length; i++) {
  if (args[i] === '--target-dir' && args[i + 1]) {
    targetDirArg = args[i + 1];
    i++; // skip next arg
  }
}

// Resolve and normalize — fallback to pre-OBJ-07 __dirname-based derivation for backward compat
const targetDir = targetDirArg
  ? path.resolve(targetDirArg).replace(/\\/g, '/')
  : path.resolve(__dirname, '../../..').replace(/\\/g, '/'); // existing CWD-relative derivation
```

**Bash script** (`install-agy.sh`, `uninstall-agy.sh`):
```bash
TARGET_DIR=""
for arg in "$@"; do
  case "$arg" in
    --target-dir)
      shift
      TARGET_DIR="$1"
      ;;
  esac
done
# If not set, derive from SCRIPT_DIR (backward compatible)
if [ -z "$TARGET_DIR" ]; then
  TARGET_DIR="$(cd "${SCRIPT_DIR}/../.." && pwd)"
fi
# Forward-slash normalization
TARGET_DIR="$(echo "${TARGET_DIR}" | tr '\\' '/')"
```

> **Backward Compatibility Guarantee**: When `--target-dir` is absent, `targetDir` resolves identically to `rootDir` in the pre-OBJ-07 scripts. Every existing call to these scripts without the new flag behaves exactly as before.

### 3.2 `ecc-items.json` Self-Contained Copy Protocol

The installation pipeline adds a final copy step after all component assets are deployed:

```javascript
// Executed at end of install-apply-agy.js main()
const masterEccItems = `${rootDir}/harness/ecc-items.json`;
const targetEccItems = `${targetDir}/.agents/ecc-items.json`;
fs.copyFileSync(masterEccItems, targetEccItems);
console.log(`[Install] ✓ Copied ecc-items.json → ${targetDir}/.agents/ecc-items.json`);
```

The verification script derives its reference path from `targetDir`, not from `rootDir`:

```javascript
// In verify-installation-agy.js, when --target-dir is active:
const ECC_ITEMS_FILE = `${targetDir}/.agents/ecc-items.json`;
// vs. existing master harness behaviour (no --target-dir):
// const ECC_ITEMS_FILE = `${REPO_ROOT}/docs/OBJ-01/artifacts/ecc-items.json`;
```

### 3.3 Rollback Safety Boundary (`uninstall-agy.sh`)

The key architectural change in `uninstall-agy.sh` is replacing the hardcoded `ROOT_DIR` derivation with a conditional `TARGET_DIR`:

```bash
# Pre-OBJ-07 (hardcoded):
ROOT_DIR="$( cd "${SCRIPT_DIR}/../.." && pwd )"

# Post-OBJ-07 (parameterized):
if [ -n "${TARGET_DIR}" ]; then
  ROOT_DIR="${TARGET_DIR}"
else
  ROOT_DIR="$( cd "${SCRIPT_DIR}/../.." && pwd )"  # backward compatible
fi
```

This single change is sufficient. All existing cleanup steps (`rm -rf ${ROOT_DIR}/.agents/plugin/ecc`, `rm -rf ${ROOT_DIR}/.agents/rules`, etc.) automatically operate against the target directory. The safety audit at the end of the script explicitly confirms `ECC/` and `website/` remain untouched regardless of `TARGET_DIR`.

**Critical Safety Invariant**: `uninstall-agy.sh` NEVER removes `${TARGET_DIR}/package.json`, `${TARGET_DIR}/src/`, or any file outside `${TARGET_DIR}/.agents/`. The cleanup list is scoped exclusively to the known `.agents/` subdirectories and `hooks.json`.

## 4. Decision Matrix

| Decision | Selected Option | Rationale | Alternatives Considered |
|---|---|---|---|
| **`ecc-items.json` reference source during `--target-dir` verification** | Copy into `<target-dir>/.agents/ecc-items.json` during installation; verifier reads from there | Makes the target directory fully self-contained — verification requires no network access, no harness path knowledge, and no environment variables. | Always read from master harness; rejected because it creates a hard dependency between the target verification run and the master harness path, violating self-containment. |
| **Rollback scope when `--target-dir` is provided** | Remove only `<target-dir>/.agents/` — no project source files touched | Project files (`package.json`, `src/`, `.gitignore`) are owned by the target repo owner and must never be silently deleted by an external installer. The `.agents/` boundary is the only safe cleanup scope. | Full target-dir `rm -rf`; rejected immediately as catastrophically destructive for any real external repository. |
| **Runtime script deployment to target-dir** | Mirror `.agents/scripts/` and `.agents/scripts/lib/` 1:1 into `<target-dir>/.agents/scripts/` | The target repository must be fully autonomous — running `hooks.json`-referenced scripts must work without the master harness being present or accessible. Deployed scripts must contain zero absolute harness paths. | Reference scripts from master harness via absolute path; rejected because it violates the zero-external-environment-variable invariant and breaks when harness is absent. |
| **Test sandbox lifecycle** | Committed as minimal scaffold (`package.json`, `.gitignore`, `README.md`) to `agy-os` git; `.agents/` is gitignored | A committed scaffold provides a reproducible, clean starting state for every test run. Ephemeral creation risks test flakiness if creation fails. `.agents/` must be gitignored to prevent accidentally committing generated installation artifacts. | Fully ephemeral sandbox; rejected because it adds a non-trivial creation step to every test run and makes CI reproduction harder. |

## 5. Non-Destructive Rollback Architecture

### 5.1 Rollback Trigger Conditions

Rollback is triggered when:
- `verify-installation-agy.js --target-dir <path>` exits with code 1 (any missing, extra, or invalid component in target).
- Any step in the `install-apply-agy.js --target-dir` pipeline fails mid-execution (Fail-Fast abort before source cleanup).
- The user explicitly runs `uninstall-agy.sh --target-dir <path>` to revert a previous installation.

### 5.2 Rollback Execution — `uninstall-agy.sh --target-dir <path>`

The extended uninstall script performs a scoped, ordered cleanup targeting **exclusively** `<target-dir>/.agents/`:

```bash
# Step 1: Determine ROOT_DIR from --target-dir (or harness default)
ROOT_DIR="${TARGET_DIR:-$( cd ${SCRIPT_DIR}/../.. && pwd )}"

# Step 2: Scope cleanup ONLY to .agents/ subtree inside ROOT_DIR
rm -rf "${ROOT_DIR}/.agents/agents/"
rm -rf "${ROOT_DIR}/.agents/plugin/ecc/"   # legacy path if present
rm -rf "${ROOT_DIR}/.agents/rules/"
rm -rf "${ROOT_DIR}/.agents/workflows/"
rm -rf "${ROOT_DIR}/.agents/skills/"
rm -rf "${ROOT_DIR}/.agents/scripts/"
rm -f  "${ROOT_DIR}/.agents/hooks.json"
rm -f  "${ROOT_DIR}/.agents/ecc-items.json"  # self-contained copy also cleaned

# Step 3: Safety audit — confirm ECC/ and website/ are untouched
echo "[VERIFIED] ECC/ repository untouched"
echo "[VERIFIED] website/ repository untouched"
echo "[VERIFIED] Project source files in ${ROOT_DIR} untouched (package.json, src/, etc.)"
```

### 5.3 Atomicity & Partial-Failure Recovery

- **Install atomicity**: `install-apply-agy.js` uses a sequential copy pipeline. If any `fs.copyFileSync` or `fs.mkdirSync` throws, `process.exit(1)` is called immediately. The source master harness `.agents/` is never modified, so the harness is always in a known good state.
- **Rollback idempotency**: `uninstall-agy.sh` uses `if [ -d ... ]` / `if [ -f ... ]` guards before every `rm` call. Re-running rollback on an already-cleaned target directory is safe and exits with code 0.
- **Dry-run safety gate**: `--dry-run` mode previews the complete cleanup plan with `[DRY-RUN]` prefixed output and makes zero disk mutations, allowing safe inspection before committing to rollback.

### 5.4 Safety Invariants (Absolute)

| Invariant | Guarantee |
|---|---|
| `ECC/` source files | **NEVER** modified or deleted by any OBJ-07 operation |
| `d:/CLAUDE-PROJECT/website` | **NEVER** touched by any OBJ-07 operation |
| `<target-dir>/package.json` | **NEVER** deleted or modified by `uninstall-agy.sh` |
| `<target-dir>/src/` | **NEVER** in scope for any cleanup operation |
| Master harness `.agents/` | **UNTOUCHED** when installer runs with `--target-dir` pointing elsewhere |
| `<target-dir>/.agents/` | The **only** cleanup scope for `uninstall-agy.sh --target-dir <path>` |
